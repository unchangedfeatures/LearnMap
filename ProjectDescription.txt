# Project Brief: LearnMap — AI-Powered Personalized Learning  ## 1. Product Overview LearnMap is a mobile-first, AI-driven learning platform that transforms static educational topics into dynamic, personalized roadmaps. It targets lifelong learners, students, and professionals who need structured paths through complex subjects without the friction of manual planning.  ## 2. Core Value Proposition - **Instant Personalization:** AI generates structured learning paths based on user goals, current level, and available time. - **Data-Driven Mastery:** Visual progress tracking via activity heatmaps and subject mastery radar charts. - **Adaptive Assessment:** Integrated quizzes that identify weak spots and suggest targeted review material. - **Seamless Continuity:** Cross-platform experience (Mobile & Desktop) ensuring learning can happen anywhere.  ## 3. Target Audience - **Self-Taught Developers/Professionals:** Users looking to pivot careers or master specific technical stacks (e.g., React Mastery). - **Academic Students:** Learners seeking supplementary structure for their curriculum. - **Knowledge Enthusiasts:** Casual learners exploring new interests (Science, Art, History).  ## 4. Key Features & Functionality  ### A. AI Roadmap Engine - **Topic-to-Path:** Users enter a subject, and the AI generates a multi-chapter roadmap. - **Personalization Flow:** Deep-dive onboarding questions (Goal, Interests, Exam Prep, Struggles) to calibrate the roadmap. - **Premium Uploads:** Ability to upload notes/PDFs to generate a custom journey (Subscription required).  ### B. Learning Experience - **Interactive Map:** A visual, node-based graph representation of the learning journey. - **Guide View:** Clean, focused reading environment for lesson content. - **Quizzes:** Interactive multiple-choice assessments with immediate feedback and XP rewards.  ### C. Progress & Analytics - **Activity Heatmap:** GitHub-style visualization of daily learning streaks. - **Subject Mastery Radar:** Hexagonal chart showing competency across different domains (Logic, Coding, Science, etc.). - **XP & Gamification:** Experience points, levels (e.g., Level 4 Learner), and streak tracking to drive retention.  ### D. Monetization (Freemium Model) - **Free:** 3 AI Roadmaps per month, basic progress tracking. - **Student ($7/mo):** Unlimited Roadmaps, advanced analytics, priority AI responses, offline mode. - **Family ($14/mo):** Up to 5 profiles, parental dashboard.  ## 5. Design Identity (Cognitive Flow) - **Primary Color:** #4361EE (Royal Blue) - symbolizes trust and focus. - **Typography:** Inter (Sans-serif) - chosen for high legibility across small mobile screens and dense desktop dashboards. - **Visual Style:** Clean, card-based UI with generous whitespace, soft shadows, and rounded corners (8px/12px) to reduce cognitive load. - **Device Support:**      - **Mobile:** Optimized for one-handed use, bottom navigation, and 44px tap targets.     - **Desktop:** Persistent sidebar, 12-column grid, and expanded data visualizations.  ## 6. User Journey Map 1. **Welcome/Onboarding:** User sets their profile and initial goal. 2. **Deep-Dive Assessment:** AI asks specific questions to tailor the first roadmap. 3. **Roadmap Generation:** A "Ready" transition state while the AI structures the plan. 4. **Active Learning:** User navigates the Map View, reads Guides, and completes Quizzes. 5. **Progress Review:** User checks their Profile to see XP gains and mastery growth. 6. **Subscription:** User hits a limit or desires premium features and navigates to Pricing.  ## 7. Technical Requirements & Accessibility - **Responsive Design:** Fluid transitions between mobile and desktop layouts. - **Accessibility:** Minimum contrast ratios for text, clear focus states, and tap target optimization. - **Loading States:** Purposeful loading transitions (e.g., Topic Loading State) to manage AI generation latency perception. Tech stack:  * Frontend: Next.js 14 App Router + TypeScript * Styling: Tailwind CSS + shadcn/ui * Backend/API: Next.js route handlers * Database/Auth/Storage: Supabase * Deployment: Vercel for the Next.js app, Supabase for database/auth/storage * AI: custom OpenAI-compatible endpoint, not direct Anthropic/OpenAI SDK  AI requirements:  * Never import Anthropic SDK or OpenAI SDK directly. * All AI calls must go through one wrapper: `lib/ai/client.ts`. * The endpoint must be configurable through environment variables:    * `AI_ENDPOINT_URL`   * `AI_API_KEY`   * `AI_MODEL_FAST`   * `AI_MODEL_SMART` * Assume the endpoint may return either OpenAI-compatible responses:    * `data.choices[0].message.content` * Or Anthropic-style responses:    * `data.content[0].text` * The app must support Claude-like and DeepSeek-like responses through the same wrapper. * All AI JSON outputs must be parsed safely and validated with Zod before inserting into Supabase. * If AI returns invalid JSON, retry once with a JSON repair prompt.  MVP product flow:  1. User opens the app. 2. User enters any topic, for example “Mathematics”, “World History”, “Biology”. 3. App calls `/api/ai/topic-questions`. 4. AI generates 4 topic-specific clarifying questions with answer chips. 5. User answers the questions. 6. User answers basic profile questions:     * age group: school, university, adult, senior    * learning style: examples, logic, stories, direct    * goal: exam, career, curiosity, understand specific topic    * optional extra context 7. App calls `/api/ai/roadmap`. 8. AI generates a personalized roadmap:     * 5–6 chapters    * each chapter has 5–6 guide titles    * first chapter is available    * other chapters are locked    * first guide of first chapter is available 9. Roadmap is saved to Supabase. 10. User sees a clean visual roadmap screen. 11. User can open an available guide. 12. App generates guide content on demand through `/api/ai/guide`. 13. User completes guide, earns XP, unlocks next guide. 14. After all guides in a chapter are complete, quiz unlocks. 15. Quiz is generated through `/api/ai/quiz`.  Authentication strategy:  * Use Supabase anonymous auth from the beginning so users can create roadmaps without signing up. * Do not force login for the first MVP. * Anonymous users should still have a stable `auth.uid()` so their roadmaps and progress belong to them. * Later, we will add email/Google login and allow anonymous users to upgrade their account. * Use Row Level Security where practical. * Never expose `SUPABASE_SERVICE_ROLE_KEY` to the browser. * Server-only secrets must only be used in Next.js route handlers or server utilities.
